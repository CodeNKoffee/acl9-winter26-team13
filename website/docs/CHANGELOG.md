# Changelog

All notable changes are documented here using [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [Unreleased]

### Added

- Versioned user guide in `website/docs/wiki/` and a script for publishing it to GitHub Wiki.

## [1.2.1] - 2026-10-17

### Fixed

- Moved the Vercel configuration into `website/` and corrected install, build, and output paths for that Root Directory.
- Updated the URL helper and browser checks to use the website-local security headers.
- Documented the exact Vercel settings and how to clear the older command override.

### Changed

- Added prominent website and direct Google Drive buttons to the README header.
- Set the repository About link to the project archive on Google Drive.

## [1.2.0] - 2026-10-17

### Changed

- Standardized the website, introduction, artwork, metadata, documentation, and project configuration on Team 13.
- Refreshed the Team 13 favicon, driver emblems, screenshots, and sharing images.
- Updated the planned custom domain to match the current repository identity.

## [1.1.1] - 2026-10-17

### Changed

- Updated archive, website, and guide links to the current repository name, `acl9-winter26-team13`.

## [1.1.0] - 2026-10-17

### Changed

- Grouped website source, tooling, and detailed docs under `website/` so the unchanged root ZIP is easy to find.
- Moved community guides into `.github/` while retaining their GitHub integration.
- Rewrote the root README around a prominent direct ZIP download and one crisp static preview.
- Updated Vercel configuration, CI, commands, and links for the new layout.

## [1.0.2] - 2026-10-17

### Changed

- Used the preferred display names Youssef Hesham, Hatem Soliman, Mohammed Elazab, and Tony Makaryous.
- Displayed each member's original student ID from the supplied roster.
- Updated the crew documentation and real app media.

## [1.0.1] - 2026-10-17

### Changed

- Replaced the navigation and footer wordmarks with the official white F1 SVG.
- Updated the crew section to the four verified Team 13 members, retaining illustrative driver silhouettes.
- Adjusted the crew grid for desktop, tablet, and phone widths and refreshed documentation and real app media.

## [1.0.0] - 2026-10-17

### Added

- Initial project identity for ACL, 9th Semester, Winter 26.
- Static racing showcase with a dark lights-out intro, red car hero, anonymous crew, and project overview.
- Google Drive link, on-demand archive preview, copy control, `.txt` link download, and GitHub ZIP access.
- Responsive navigation, reduced-motion support, complete no-JavaScript content, and bundled OFL fonts.
- Vercel configuration, security headers, sharing metadata, sitemap, manifest, and domain-update script.
- Repository contribution, conduct, security, licensing-scope, and release documentation.
- Real app screenshots and GIF generation, static validation, and browser checks.

### Changed

- Set up the public project repository.

The pre-existing `F1 Project Repository.zip` remains unchanged by this release. The website's version number describes the showcase, not the archived model or coursework.
