# Project archive

The main action is **Open Google Drive**. It uses the exact shared link supplied by the project owner:

[Open F1 Project Repository ZIP](https://drive.google.com/file/d/1DqSlh85tX_Q4ai2vMS4IBDJC6TlLHCPO/view?usp=sharing)

The Google Drive preview starts expanded and uses native lazy loading. **Close preview** smoothly collapses it; **Preview archive** reopens it without reloading the iframe. Reduced-motion preferences make these changes immediate. Google may be unable to preview a ZIP, or its sharing permissions may prevent access. Use the direct Drive link or **ZIP on GitHub** in that case.

**Copy Drive link** copies the shared URL to the clipboard. If browser permissions prevent this, use **Save link as .txt**, which downloads `project-link.txt`.

The original `F1 Project Repository.zip` is in the repository root, preserved unchanged by the website release. It is excluded from the deployed website bundle and stays accessible through GitHub. The project owner manages archive updates.

This guide does not claim to have extracted or validated the ZIP contents. Website version 1.0.0 is a separate version from any academic project version.
