# Your data

The website has no login, database, analytics, advertising scripts, cookies, local storage, or saved preferences. Reloading restarts the intro unless the URL points to a section. Reduced-motion settings come from the browser or operating system.

The public Drive URL is written to the clipboard only after **Copy Drive link** is selected. The `.txt` control downloads a small static text file.

The archive preview starts expanded. Its iframe uses native lazy loading, so Google Drive may load as you approach the archive section without selecting a button. Google's iframe can make its own requests and apply its own service policies. GitHub links likewise lead to GitHub. The website does not upload your files or change Drive sharing.

No offline mode or service worker is provided. Save the project from Drive or GitHub if you need a local backup, subject to the archive's own licensing and terms.
