# FAQ

**Does this website predict podiums in my browser?**

No. It introduces the academic project and provides its archive. The project brief describes a prediction pipeline; the website does not execute or certify that pipeline. See [[Project Archive]].

**Why is the Drive preview blank or unavailable?**

Google controls supported previews and file sharing. A ZIP may not preview. Choose **Open Google Drive** or **ZIP on GitHub** instead. See [[Project Archive]].

**Who are the drivers?**

The four cards introduce Team 13: Youssef Sherif, Hatem Soliman, Mohammed Elazab, and Tony Henin. Names were matched to the supplied CSEN903 Winter 2026 team roster. The helmeted figures are illustrative silhouettes; no teammate photos or student IDs are published.

**Can I skip the intro?**

Open a section URL such as `/#archive`, or enable reduced motion. The intro is brief and does not block the archive links from being present in the HTML. See [[Getting Started]].

**Can I use the code or car artwork?**

The newly authored website code is MIT. The archive, branded car image, marks, and fonts have separate terms. Read LICENSE-SCOPE.md before reusing them.

**Is the planned domain already live?**

This repository setup leaves Vercel deployment and domain configuration to the owner. See [[Self Hosting]].
