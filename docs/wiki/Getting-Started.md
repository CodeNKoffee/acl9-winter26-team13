# Getting started

The page has four main stops: the hero, **The project**, **The crew**, and **The archive**.

1. Let the short lights-out intro finish, or follow a direct section link to skip it.
2. Choose **Explore the project** to reach the archive controls, or use the navigation to read about the project and crew.
3. Select **Open Google Drive** to open the project file in a new tab.
4. Use **ZIP on GitHub** for the archive already committed at the repository root.

On phones, **Open navigation** expands the section links. Choosing a link closes the menu; Escape closes it too. **Replay intro** in the footer replays the animation, unless reduced motion is enabled.

The silhouettes represent three work disciplines; they are not a roster or a claim about the number of team members.
