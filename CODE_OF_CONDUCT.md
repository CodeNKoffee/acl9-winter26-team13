# Code of conduct

We adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference, including its community standards, enforcement responsibilities, scope, and enforcement guidelines.

Be respectful, welcome different perspectives, and give constructive feedback. Harassment, discrimination, personal attacks, and publishing private information are unacceptable. This applies in issues, pull requests, discussions, the wiki, and other project community spaces.

## Private reports

Report misconduct privately to maintainer Hatem Soliman at **hatemthedev@gmail.com**. Include the relevant context and links. Do not publish sensitive details in an issue. The maintainer reviews reports discreetly, protects reporter privacy where possible, and applies the Covenant's correction, warning, temporary-ban, or permanent-ban guidelines as appropriate.

For a security vulnerability, use [SECURITY.md](SECURITY.md) instead.
